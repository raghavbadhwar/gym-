## 2024-05-14 - Aggregate Query Optimization
**Learning:** In SQLAlchemy, replacing multiple individual `.count()` queries with a single `.group_by()` query drastically reduces database roundtrips. However, when performing this optimization on Enum columns mapped to dictionaries, the overall `total` aggregate must be computed in a separate query to correctly include records that might contain `NULL` or unmapped values. Furthermore, mapping enum values in dictionary iterations requires defensive checks (`state.name.lower() if hasattr(state, 'name') else str(state).lower()`) to safely handle driver differences and prevent key matching errors.
**Action:** Always verify if multi-count aggregates can be consolidated into a `.group_by()`. Make sure to retain a separate total count and add defensive mapping for unmapped or driver-specific enum mappings.
