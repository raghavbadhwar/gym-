## 2026-04-13 - Optimize SQLAlchemy state count aggregation
**Learning:** Replacing multiple `.count()` calls with a single `.group_by()` query significantly reduces database load and resolves N+1 query patterns. However, you must maintain a separate `.count()` query for the overall total if your grouping column allows NULL or unmapped values, as `sum(stats.values())` would exclude them. Also, when mapping enum keys from database drivers, use a robust fallback like `state.name.lower() if hasattr(state, 'name') else str(state).lower()`.
**Action:** When optimizing dashboard statistics or similar endpoints by grouping states, always check if the total needs to reflect missing/NULL attributes and retain a separate count query if so. Implement fallback parsing for ENUM database returns to handle driver-specific inconsistencies gracefully.
