## 2024-03-20 - Optimize SQLAlchemy Aggregate Queries with `group_by`
**Learning:** Database aggregation using `group_by` can significantly reduce database roundtrips for endpoints that need statistics split across multiple states. When performing group counts, one must correctly aggregate `total` from *all* records, considering `NULL` values that the group-by might return, rather than relying on another roundtrip with `.count()`.
**Action:** When querying for dashboard-style aggregate counts that filter by a single column's different states, always replace multiple `.count()` queries with a single `.group_by()` query combined with `func.count()`. Ensure null handling and correct mapping of the grouped results into a structured dictionary without missing the total accumulation.
