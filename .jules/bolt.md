## 2024-05-24 - Group By Query vs Multiple Count Queries
**Learning:** In SQLAlchemy, performing multiple `.count()` operations for different states in a table leads to the N+1 query problem, increasing overhead and execution time because a separate database connection and query is run per state. Grouping by a category column like Enum in a single query is drastically faster.
**Action:** When aggregating statistics by an enum or state column, use a single `.group_by(Model.column_name)` along with `func.count(Model.id)` to fetch all required counts at once instead of individual filtered `.count()` queries. Also remember to map the key robustly using `state.name.lower() if hasattr(state, 'name') else str(state).lower()` due to database driver nuances, and still compute total counts separately via `total = session.query(Model).count()` to handle missing values accurately.
