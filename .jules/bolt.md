## 2024-05-24 - [Optimizing multiple counts into a single grouped query]
**Learning:** In SQLAlchemy, multiple `.count()` queries on the same table but filtered by different states (e.g., active, at_risk, dormant) can cause an N+1 performance bottleneck. Using a single `.group_by()` query with `func.count(model.id)` retrieves all necessary data in one round-trip to the database, vastly improving efficiency. When iterating over the grouped results containing `Enum` values, it's critical to check for `NULL` states to correctly compute the overall total without unintentionally ignoring null-state records or crashing due to missing `.value` attributes on `None`.
**Action:** When asked to calculate summary statistics split by a categorical column, use a single `.group_by()` query rather than issuing multiple specific `.count()` queries. Ensure the resulting grouped data is iterated safely, gracefully handling potential `NULL` values to accurately build the total aggregated statistics.
