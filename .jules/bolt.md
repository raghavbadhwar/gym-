## 2026-03-02 - Pre-compiled regex patterns for string parsing performance
**Learning:** Frequent invocation of `re.search` inside common conversational loops like intent routing, AI fallbacks, and parameter parsing introduces measurable runtime overhead since Python compiles the pattern each time. The fallback parsing functions inside `ai_engine.py` (e.g. `_rule_based_classify` and `_rule_based_parse_booking`) and `chat.py` were defining and executing `re.search` repeatedly.
**Action:** When working on text analysis patterns, especially in fallback paths or conversational loops, extract regular expressions into module-level constants and use `re.compile()` immediately to build standard, pre-compiled patterns. Then call `.search` (e.g., `TIME_MATCH_PATTERN.search(text)`) instead of `re.search()`.
