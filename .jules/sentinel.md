## 2025-03-19 - [Missing HMAC-SHA256 Validation on Webhooks]
**Vulnerability:** The WhatsApp webhook endpoint (`/api/v1/webhooks/whatsapp`) lacked signature verification using the `X-Hub-Signature-256` header, allowing potential spoofing of webhook payloads from unauthenticated sources.
**Learning:** Even though the verification endpoint (`GET /whatsapp`) checked a static `whatsapp_verify_token`, the actual message reception endpoint (`POST /whatsapp`) did not validate that the payload actually originated from Meta using the app secret. Also, explicitly catching `HTTPException` in FastAPI error handlers is necessary to prevent them from being swallowed by generic `except Exception` blocks and incorrectly returning a 200 OK status instead of a 401 Unauthorized or 500 Server Error.
**Prevention:** Implement HMAC-SHA256 signature verification on all incoming webhooks using `hmac.compare_digest` to prevent timing attacks, and enforce fail-secure defaults if secrets are missing. Ensure explicit handling of `HTTPException` in broad try-except blocks.
