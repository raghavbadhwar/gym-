## 2025-03-08 - [CRITICAL] Fix Missing Webhook Authentication
**Vulnerability:** The WhatsApp webhook endpoint (`POST /api/v1/webhooks/whatsapp`) was processing incoming messages without validating the `X-Hub-Signature-256` header. Additionally, the `GET /api/v1/webhooks/whatsapp` verification endpoint used a standard string equality check (`==`) instead of a constant-time comparison for the verification token.
**Learning:** This codebase handles sensitive integrations like WhatsApp Webhooks which mandate verifying payload signatures. The framework provides automatic access to the unparsed payload using `await request.body()`, but security controls need explicit implementation to securely validate requests from third parties like Meta and fail safely (returning HTTP 500 when `whatsapp_app_secret` is unset) to prevent misconfiguration exploits.
**Prevention:** Always validate payload signatures using HMAC SHA256 when exposing endpoints to external webhooks. When configuring webhook verification tokens or signatures, always use `hmac.compare_digest` or `secrets.compare_digest` to mitigate timing side-channel attacks. Make security variables required via failing loudly (Fail Secure) if missing.
