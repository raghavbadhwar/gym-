## 2024-05-18 - [Missing Webhook Signature Validation]
**Vulnerability:** The WhatsApp webhook endpoint (`/api/v1/webhooks/whatsapp` POST) accepted any payload without verifying the `X-Hub-Signature-256` header from Meta. This would allow an attacker to spoof messages and potentially inject malicious payloads or trigger unintended actions.
**Learning:** The initial implementation relied solely on the initial GET request verification and missed the ongoing message signature validation required for secure webhook operation. Webhooks must always validate the payload signature to ensure it originates from the expected sender.
**Prevention:** Always implement HMAC-SHA256 signature validation using the configured App Secret for all incoming webhook requests. Use secure constant-time comparison methods like `hmac.compare_digest` to prevent timing attacks. Provide an explicit `except HTTPException: raise` block to ensure fail-secure HTTP error codes are correctly returned and not caught as general 500 errors.
