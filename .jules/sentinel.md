## 2024-04-12 - Missing Meta Webhook Signature Validation
**Vulnerability:** The WhatsApp webhook endpoint (`/api/v1/webhooks/whatsapp`) received POST requests and processed messages blindly, failing to validate the `X-Hub-Signature-256` header. This allowed malicious actors to craft and send arbitrary messages to the server by simply formatting requests in the WhatsApp schema, leading to potential abuse and spoofing.
**Learning:** Webhook endpoints that accept business/customer data without signature validation are critical security gaps, especially those from major providers like Meta. Furthermore, general exception handlers (`except Exception`) can swallow security errors (like HTTP 401 Unauthorized), resulting in fail-open scenarios where unauthorized access might return a 200 OK.
**Prevention:** Always implement `hmac.compare_digest` validation on webhook POST payloads using the app's secret. Explicitly re-raise specific `HTTPException` types (like 401) before any broad `Exception` handler to ensure fail-secure behavior.
