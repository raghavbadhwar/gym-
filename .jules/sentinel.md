## 2025-03-16 - [Fix missing webhook signature validation]
**Vulnerability:** The WhatsApp webhook endpoint (`/whatsapp` POST) in `app/routers/webhooks.py` lacked `X-Hub-Signature-256` payload validation and used a simple string equality check for the verification token (GET). This allowed potential impersonation of Meta webhooks by malicious actors and introduced timing attack vulnerabilities.
**Learning:** Security-critical endpoints, especially webhooks accepting external payloads, must actively enforce signature verification using secure string comparison functions (`hmac.compare_digest`, `secrets.compare_digest`). Additionally, implementing a "Fail Secure" strategy (e.g., raising HTTP 500 when configuration secrets like `whatsapp_app_secret` are missing) ensures the system never processes unverified payloads in an insecure default state.
**Prevention:** Enforce signature validation on all webhooks receiving external events. Use `secrets.compare_digest` for secret equality checks to prevent timing attacks. Enforce "Fail Secure" for missing critical configurations.
