## 2026-03-18 - Missing Webhook Signature Verification
**Vulnerability:** The WhatsApp webhook endpoint (`POST /whatsapp`) accepted messages without verifying the `X-Hub-Signature-256` signature sent by Meta. This allowed potential spoofing of incoming messages from unauthenticated attackers.
**Learning:** External-facing webhooks handling sensitive data (like user chat messages) must explicitly validate signatures to authenticate the sender. A "fail secure" implementation was needed to return 500 when the verification secret (`whatsapp_app_secret`) is missing, ensuring the system doesn't accidentally default to open access. Furthermore, Python's `hmac.compare_digest` must be used over `==` to prevent timing attacks when comparing hashes.
**Prevention:** Implement signature validation using `hmac` for any new webhook integrations from third parties, ensuring the app secret is checked upon startup or request reception. Include negative test cases for missing signatures, invalid signatures, and missing secrets.
