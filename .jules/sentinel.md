## 2024-05-24 - [Missing Webhook Signature Validation]
**Vulnerability:** The WhatsApp webhook endpoint (`/api/v1/webhooks/whatsapp` POST) was accepting payloads without validating the `X-Hub-Signature-256` header, making it susceptible to spoofed requests. Additionally, `HTTPException`s thrown during the process were swallowed by a general `except Exception as e:` block, which caused the endpoint to return a 200 OK status instead of properly raising a 401 Unauthorized status when authentication/authorization failed.
**Learning:** In FastAPI, broad exception handling can swallow specific framework exceptions like `HTTPException`. When implementing webhook signature verification, both the signature validation itself and the proper propagation of exceptions are critical to prevent "fail-open" scenarios.
**Prevention:** Always extract raw byte payloads using `await request.body()` for HMAC verification. Catch and re-raise `HTTPException` explicitly before generic `Exception` handlers in API endpoints. Use `hmac.compare_digest` for secure, constant-time string comparisons.
