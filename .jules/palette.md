## 2024-04-15 - Interactive Dashboard Input Accessibility
**Learning:** Raw input fields lacking explicit `<label>` tags and icon-only SVG buttons in custom dashboards frequently break screen reader announcements, rendering the interface silently interactive. Providing explicit `aria-label` attributes to inputs and interactive buttons, along with explicitly hiding inner SVG elements using `aria-hidden="true"`, ensures proper contextual announcements without altering the visual design layout.
**Action:** Always scan custom interactive layouts (such as chat simulators or custom form inputs) for standalone inputs and icon buttons. When visible text labels cannot be added due to design constraints, apply `aria-label` directly to the semantic element and hide non-semantic decorative contents like SVGs using `aria-hidden="true"`.
