## 2024-05-24 - [Accessible Command Cards Pattern]
**Learning:** In the `dashboard/index.html` chat simulator interface, interactive command cards (`.command-card`) were initially structured as `div`s with `onclick` handlers, rendering them inaccessible to keyboard users and lacking semantic meaning for screen readers. When converting these to native `<button>` elements, we found that inner nested wrappers (originally `<div class="cmd-info">`) had to be converted to `span`s because HTML5 specifies that `<button>` elements should only contain phrasing content (block-level `div`s inside buttons are invalid HTML).
**Action:** When implementing interactive list items or card-like widgets across the design system, default to using native `<button>` elements styled to look like cards. Use `span` tags for internal grouping to ensure valid phrasing content and apply CSS resets (`appearance: none`, `text-align: left`, etc.) combined with `:focus-visible` styling to maintain visual structure while ensuring full keyboard accessibility.
